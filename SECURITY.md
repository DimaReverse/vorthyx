# Security reports

Binary files and extracted metadata are untrusted inputs. Analyze unfamiliar samples in an isolated environment. Static analysis does not guarantee that the parser itself is free from vulnerabilities.

For a parser vulnerability, unsafe output path, unexpected execution, or a secret exposure, use this repository's **Security → Report a vulnerability** option if it is enabled. If unavailable, open an issue asking for a private reporting channel without including exploitation details or sensitive data.

Include the affected commit, platform, a minimal synthetic input when possible, and a description of the impact. Do not publish secrets, private samples, or weaponized reproductions. This research project has no guaranteed response time or support SLA.
