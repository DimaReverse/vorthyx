# VORTHYX 0.1.0 — open research preview

VORTHYX gives my continuing Nuitka recovery work a new home: the integrated NDX engine, static extraction and bytecode export, recovery reports, and existing synthetic regression fixtures.

This release includes English and Italian introductions, documentation of the two CLI interfaces, MIT notices, community contribution templates, and a Windows/Linux CI configuration.

Thank you to everyone who followed my story, suggested features, reported bugs, tested fixes, or built a fork. Your support helped this project continue.

Local publication checks: 35 tests passed and one optional external-fixture test was skipped on Windows with Python 3.11. Both CLI help paths and source compilation were checked. The compiled Nuitka matrix and GitHub-hosted CI results are separate from these local checks.

Native recovery remains best effort. No complete-recovery, universal-support, or comparative-performance claim is made. See `docs/LIMITATIONS.md` before evaluating output.
